# Chemin d'Etoudi

Simulation réaliste de la vie politique et sociale au Cameroun (2026), en français.

**Jouer :** https://raw.githack.com/farroteur2016-afk/chemin-etoudi/main/index.html

- `index.html` : le jeu complet, en un seul fichier, jouable dans Chrome sur PC, tablette ou téléphone, sans compte.
- `ultra-*.js` : graphismes réalistes (mode Ultra, chargés à la demande).
- `actus.json` : actualités réelles du Cameroun, mises à jour chaque jour.
- `src/` : code source.
